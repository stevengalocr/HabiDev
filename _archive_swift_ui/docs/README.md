## 💡 Filosofía del Proyecto

HabiDev está construido siguiendo estos principios:

- **Clean Architecture**: Separación clara de responsabilidades
- **MVVM**: Separación de UI y lógica de negocio
- **Protocol-Oriented**: Interfaces sobre implementaciones concretas
- **Dependency Injection**: Facilita testing y mantenibilidad
- **SwiftUI Best Practices**: Aprovecha al máximo el framework de Apple
